# Pi Zero Master Monitor 📡

A lightweight, headless monitoring stack designed for the Raspberry Pi Zero. It monitors local system health (temperature, RAM, under-voltage) and sweeps the local network to ensure critical devices are online. 

Alerts and daily reports are delivered via the Gmail API using OAuth2, preventing email spam by utilizing a state-tracking flag file.

## 📂 File Directory

### Core Scripts
* `pi_monitor.py` - The master watchdog script. Runs via cron. Checks hardware health, pings network devices, writes to the log, and sends emails.
* `generate_devices.py` - A utility script that uses `nmap` to scan the local subnet and automatically generate the `devices.json` file.

### Configuration Files
* `settings.json` - The master configuration file. Contains email recipient lists, temperature thresholds, and logging preferences.
* `devices.json` - A key-value list of friendly names and IP addresses for the network ping sweep. (Can be hand-edited or generated by `generate_devices.py`).

### Authentication & State (Auto-Generated)
* `credentials.json` - Your downloaded Google Cloud Desktop OAuth client secrets (Requires manual download from Google Cloud Console).
* `token.json` - Generated automatically upon first authentication. Stores the refresh token for headless email sending.
* `alert_sent.bin` - A temporary flag file created when an alert is sent. Prevents the script from spamming your inbox while the issue is actively occurring.
* `pi_monitor.log` - The rotating log file. Tracks script execution, errors, and system status history.
